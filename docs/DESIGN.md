# AquaEscape 설계서

**+1 Speed Keyboard Escape 같은 걷기 클리커**를 기본으로 하고, 그 위에 어비스리움의 성장 시스템(물고기 복리, 산호 방치 수익, 레벨업 구조)을 얹은 로블록스 게임.
화면을 탭하지 않는다. **걸음이 곧 클릭**이다.
시스템만 참고하며, 에셋·이름·코드는 모두 새로 만든다.

## 1. 핵심 루프

```
Escape 코스에서 걷기 → 걸음마다 Speed +1, 생명력 +걸음당 값
        ↓
걸음 강화 · 물고기 창조 · 산호 구매 → 걸음당 생명력 / 초당 생명력 증가
        ↑
Speed 상승 → 이동속도 증가(걸음 수 증가) + 소폭 생산량 배수
        ↓
코스 클리어 → 보석 보상, KillBrick에 닿으면 시작점 복귀 (Speed는 유지)
```

걷기가 돈이 되고, 어비스리움 시스템이 그 효율을 복리로 키운다. 산호는 걷지 않을 때도 생명력을 모아 주는 방치 수익이다.

## 2. 어비스리움에서 가져온 시스템

| 항목 | 규칙 | 구현 위치 |
|---|---|---|
| 생명력 | 단일 화폐. 걸음당 + 초당(산호) 두 갈래 | `Economy.stepValue`, `Economy.passivePerSecond` |
| 걸음 강화(원작의 산호석) | 레벨당 비용 +7%, 25레벨마다 걸음당 생명력 2배 | `Economy.stoneCost*` |
| 물고기 | 창조할 때마다 모든 생산량 2배(복리), 가격 증가율은 구간표 | `Economy.fishCost` |
| 산호 | 방치 수익, 25레벨마다 2배, 이전 산호가 있어야 해금 | `Economy.coral*` |
| 방치 보상 | 접속하지 않은 동안 최대 3시간 | `Main.server.luau` `onJoin` |
| 숫자 표기 | 1A=1000, 1B=1000A, ..., 1Z, 1AA ... | `NumberFormat` |

물고기 가격 증가율 (n번째 창조 직후 다음 가격에 곱해지는 값):

| 창조 횟수 | 1~2 | 3 | 4~9 | 10~59 | 60~69 | 70~80 | 81~ |
|---|---|---|---|---|---|---|---|
| 배율 | ×5 | ×53.24 | ×11 | ×7 | ×6 | ×5 | ×3.5 |

25레벨 일괄 구매가 효율적인 이유: 25레벨 비용 = 현재 비용 × (1.07²⁵ − 1) / 0.07 ≈ 63.25배. 이 비용과 물고기 가격을 비교해서 싼 쪽을 사는 것이 어비스리움의 핵심 판단이며, UI에 두 버튼을 나란히 둔 이유다.

## 3. Keyboard Escape에서 가져온 시스템

- 걸음당 +1 Speed (서버가 직접 잰 이동 거리 3 studs = 1걸음)
- Speed가 오를수록 WalkSpeed 증가 (상한 80)
- 실수하면 시작점으로 복귀 (KillBrick). 어비스리움의 "힐링" 느낌을 해치지 않도록 Speed는 잃지 않는다.
- `leaderstats.Speed`로 서버 내 속도 순위 표시

## 4. 서버 권위 / 어뷰징 방지

- 클라이언트는 `Action` 리모트로 의도만 보낸다 (`UpgradeStone`, `CreateFish`, `BuyCoral`). 비용 검증과 지급은 전부 서버.
- 생명력 획득은 클라이언트가 요청할 수 없고, 서버가 계산한 걸음에서만 생긴다.
- 걸음은 서버가 0.1초마다 HumanoidRootPart 위치로 계산한다. 한 틱에 갈 수 있는 거리를 넘는 이동(순간이동)은 무시한다.
- DataStore 로드에 실패한 플레이어는 빈 데이터로 덮어쓰지 않도록 저장하지 않는다.

## 5. 맵 제작 규칙 (Studio에서 직접 만들어야 하는 부분)

CollectionService 태그로 연결한다.

| 태그 | 용도 |
|---|---|
| `EscapeZone` | 걸음이 집계되는 영역. 키보드 코스 전체를 덮는 투명 파트 |
| `KillBrick` | 닿으면 시작점 복귀 |
| `EscapeGoal` | 닿으면 보석 지급(Attribute `Gems`, 기본 25) 후 복귀 |
| `EscapeSpawn` | 복귀 위치 (첫 번째 파트 사용) |

## 6. 다음 단계 후보

1. 스킬: 화산 폭발(자동 걸음), 맛있는 먹이(즉시 보상), 달의 노래(생산량 버프) + 쿨타임
2. 코스 단계(Stage)별 Speed 요구량과 해금
3. 보석/진주 상점, 출석 보상, 일일 미션
4. 물고기 시각화 (수족관 안에서 헤엄치는 모델)
5. 코랄 수치 밸런싱 (현재 `Config.Corals`는 자리표시 값)
