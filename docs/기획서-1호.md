# 게임 기획서 — 1호

## 한 줄 요약
달리면서 속도 수치를 쌓고, 스테이지를 클리어해 코인을 벌고, 그 코인으로 어항에 물고기를 사서 속도 누적 배율을 올리는 키우기 게임. 캔디/초콜릿 키보드 키 모양의 길을 달린다.

## 레퍼런스 구조
구조만 참고한다. 이름, 모델, 사운드, 설명글, 수치표는 복사 금지. 전부 직접 만든다.

"+1 Speed Keyboard Escape" 류 게임의 구조:

- 스테이지(장애물 코스)를 달려 끝의 버튼을 누르면 "승리"(화폐)를 얻고 시작 지점으로 텔레포트된다.
- 스테이지마다 권장 레벨이 있고, 뒤쪽 스테이지일수록 어렵지만 보상이 2~3배씩 커진다.
- 걸음마다 "속도" 수치가 누적된다. 이 수치는 실제 이동 속도가 아니라 화면에 표시되는 성장 숫자이고, 배율이 계속 곱해져서 K, M, B, T 같은 단위로 표기된다.
- 성장이 쌓이면 예전에 어렵던 구간이 쉬워진다. 이동 속도가 충분하면 점프로 틈을 한 번에 건너거나 구간을 건너뛰는 숏컷이 열린다. (이 "예전엔 못 넘던 걸 넘는 느낌"이 성장 체감의 핵심이다)
- 승리로 트레일/아우라 같은 "속도 배율 아이템"을 산다. (우리는 이 자리를 물고기가 대신한다)
- 스테이지 유형은 다양하다: 점프맵, 추격, 사라지는 길, 파도, 장애물 피하기, 좁아지는 벽, 중력 발판, 벽 달리기, 감시. 1호에서는 점프맵만 만든다.
- 환생, 아이템 뽑기/병합, 러닝머신, 이벤트 버프 등은 전부 후반 콘텐츠다. 1호에서는 만들지 않는다.

## 핵심 루프
1. 달린다. 걸음마다 속도 수치 += 1 × 총 배율 (총 배율 = 1 + 보유 물고기 배율 합)
2. 속도 수치가 쌓일수록 실제 이동 속도가 완만하게 오르고, 점프로 건너는 거리도 늘어난다.
3. 그래서 더 어려운(틈이 넓은) 스테이지를 깰 수 있게 된다.
4. 스테이지 끝 버튼을 누르면 그 스테이지의 고정 보상만큼 코인을 얻고 시작 지점으로 텔레포트된다. 뒤쪽 스테이지일수록 보상이 2~3배씩 크다.
5. 코인으로 물고기를 산다. 물고기는 어항에서 헤엄친다.
6. 물고기 배율 때문에 속도 수치가 더 빨리 쌓인다. 1번으로 돌아간다.

## 1호 스코프
- 스테이지 3개 (키보드 키 모양 파트, 기본 파트 + 색). 전부 점프맵: 일직선 길에 점프로 건너는 틈이 있고, 뒤로 갈수록 틈이 넓다.
- 난이도 게이팅은 이동 속도로 한다. 스테이지 3의 틈은 처음 속도로는 못 넘고, 속도가 쌓이면 넘을 수 있게 설계한다.
- 모바일 조작이 불안정하니 틈은 넉넉하게 만든다. (원본도 점프가 너무 어렵다는 불만 때문에 여러 스테이지를 쉽게 고쳤다)
- 각 스테이지 입구에 "권장 속도" 표지판을 둔다.
- 스테이지 끝에 클리어 버튼. 누르면 코인 지급 + 시작 지점 텔레포트.
- 스테이지 보상 (임시값): 스테이지1 = 10코인, 스테이지2 = 30코인, 스테이지3 = 100코인.
- 길에서 떨어지면 시작 지점으로 리스폰한다. (속도 수치는 유지)
- 걸음 감지는 서버에서 처리한다. 이동 중일 때 일정 간격마다 1걸음으로 센다.
- 속도 수치는 큰 숫자를 다루므로 K / M / B / T 단위 표기 함수를 만든다.
- 실제 이동 속도(WalkSpeed)는 속도 수치와 별개다. 기본값에서 시작해 속도 수치가 쌓일수록 완만하게(로그 곡선 등) 올리고, 임시 상한(예: 50)에서 멈춘다. 속도 수치를 WalkSpeed에 그대로 넣지 말 것.
- 어항 1개. 물고기 3종 (임시값: 가격 100 / 1,000 / 10,000, 배율 +0.5 / +1 / +2).
- HUD: 속도 수치, 코인.
- DataStore 저장: 속도 수치, 코인, 보유 물고기. 재접속하면 이어서 한다.
- 속도, 코인, 배율, 구매 계산은 전부 서버 스크립트에서 한다. 클라이언트는 표시만 한다. (치트 방지)
- 출시 자산: 아이콘, 썸네일, 설명글.
- 임시값은 전부 플레이하면서 조정한다.

## 1호에서 뺄 것 (2호 이후 후보)
- 환생 (첫 후보. 키우기 장르의 핵심 재미)
- 스테이지 기믹 확장: 사라지는 길, 파도, 장애물 피하기, 추격/보스, 중력 발판, 벽 달리기, 감시, 고속 숏컷
- 승천, 러닝머신, 트레일/아우라, 아이템 뽑기/병합
- 연승 보너스, 시간 보상, 코드 입력, 이벤트 버프
- 래그돌 물리, 서버 랭킹, 월드 2/3
- 사운드/스킨 판매, 게임패스
- 어항 자랑/공개, 물고기 진화/도감

## 기술 환경
Rojo + Luau. 폴더: ServerScriptService / StarterPlayerScripts / ReplicatedStorage

## 작업 방식
- 한 단계씩만 작업한다. 단계가 끝나면 Studio에서 확인하는 방법을 알려줄 것.
- 이 문서에 없는 시스템은 추가하지 말고, 필요하면 먼저 물어볼 것.
